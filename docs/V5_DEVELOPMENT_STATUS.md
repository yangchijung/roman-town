# 古羅馬第一人稱遊戲：開發狀態

最終目標：史詩級第一人稱遊戲，場景精緻逼真。此目標尚未達成；目前版本是開發原型，不能視為完成的遊戲。

## 2026-10-24 部署

- GitHub：yangchijung/roman-town，main。
- 獨立開發預覽：https://roman-town.pages.dev/v5-preview
- 程式：public/v5-preview.html。保留現有 public/index.html。
- 原始交付：Gemini Canvas v5.0（上午 9:23）。
- 原版在實際瀏覽器啟動時因 DATA.terrain 缺少而中斷。資料是 hills / urbanBuildings / allLandmarks128AD / roads.waypoints，但渲染器期待 terrain / buildings / landmarks / roads.points。
- 本次補上資料格式對接，以既有 P6 地形函式生成地形取樣；將尺寸、座標、弧度與道路欄位轉為渲染器所需格式。移除未使用的重複內嵌資料。
- 修復後仍過暗，開發預覽暫時停用 environment map 與動態陰影，加入基本環境光。此項是可見性修復，並未達成寫實光照驗收。原介面的 IBL 文案不應當成已驗證的功能證據。
- 起始鏡頭改為可見的鳥瞰位置，避免原起始鏡頭遮擋。最終遊戲仍需以第一人稱作為主要模式。
- 移除 FPS 顯示的 60 上限，將介面標為開發預覽、效能待優化。Box3 結果是幾何縮放至目標尺寸後的校正誤差，不是獨立考古驗證。

## 本次確認

- JavaScript 語法檢查通過。
- 真實瀏覽器載入後可見建築；介面顯示 489 組建築、1,319 石柱／拱門。沒有新的啟動例外。
- 切換鳥瞰鏡頭可見場景。
- 桌面 1280×720 的短暫觀察約為個位數至 20 FPS 左右，明顯不適合流暢遊戲；這不是標準化效能報告，也不是 iPad 實機結果。
- Cloudflare 線上回應與上傳的 HTML SHA-256 一致，已在瀏覽器開啟線上版本。

## 下一輪必要工作

1. 改善建築比例、布局與遮擋，檢查所有鏡頭、道路與地形銜接。現有模型仍遠未達到精緻逼真要求。
2. 正確的 PBR／環境反射／曝光與陰影。不可僅以新增術語或版本名稱宣稱提升品質。
3. 第一人稱視高、滑鼠視角、自然步速、碰撞、樓梯與可行走路面。現有漫步控制缺少完整碰撞，步速也不是自然步行速度。
4. Instancing、合併幾何、LOD、可見性剔除與分區載入，以實際硬體測試為準。
5. 6 機位、漫步、光照、隱藏 UI、建築選取及量測報告的完整互動驗收。
6. 記錄首次載入、FPS 分布、draw calls、三角面、可取得的記憶體指標、裝置與瀏覽器。平板視窗模擬不能稱為 iPad Pro 實機。
7. 至少 6 張直接來自可執行瀏覽器的無 UI 截圖及前後比較。離線渲染不能取代預覽驗收。

通過品質與效能驗收後，才將新版本作為首頁的主要遊戲入口。
